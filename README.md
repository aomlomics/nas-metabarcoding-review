# Review of AIS detected in eDNA metabarcoding studies

This repository contains files associated with a systematic review of literature reporting detections of aquatic invasive species (AIS) and non-indigenous aquatic species (NAS) using environmental DNA (eDNA) metabarcoding. The purpose of this work is to inform guidelines, standards, and reporting requirements for AIS and NAS in eDNA metabarcoding data.

* This work is part of the project: Development of eDNA metabarcoding and data standards through community networks to support the USGS Nonindigenous Aquatic Species database

The structure of this repository is:

* markdown – study questions, publications included in review, analysis notes, and results
* code – R scripts for data analysis and figure generation
* figures – pre-publication versions of figures
* metadata – sample data and other metadata, prepared in standard format for database submission
