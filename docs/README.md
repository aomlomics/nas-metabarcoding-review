## Docs

This folder contains reporting checklists and supplementary materials, including the following files:

* Appendix_1_ROSES_checklist_filled.xlsx – ROSES Reporting template
* Appendix_2_Systematic_review.xlsx – list of included and excluded publications with rationale for exclusion
* Appendix_3_Included_papers.xlsx – included publications only
* Appendix_4_Study_metadata.xlsx - information about each study
